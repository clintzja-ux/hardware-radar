# IC-MERCURY-006 — Historical Intelligence

**Status:** Implemented — Pending Exit Review

## Objective
Derive deterministic historical market facts from canonical immutable Mercury observations.

## Deliverables
- Historical eligibility evaluation
- Historical query validation
- Chronological price timeline
- Lowest/highest observed price with evidence identity
- Arithmetic average
- First-to-latest absolute and percentage movement
- Historical summary
- Product/currency/condition comparability boundaries
- Optional retailer and marketplace query dimensions
- Mercury facade integration
- Regression tests
- ADR-011

## Explicit exclusions
No deal scoring, prediction, current freshness gating, publication gating, fabricated canonical observations, or mutable history store.
