# IC-DF005R — Controlled Cloudflare Recipient Configuration and Destination Verification Execution

DF005-R creates separate zero-network PREPARE and explicitly confirmed EXECUTE boundaries for the Cloudflare Email Routing destination-address operation. The production PREPARE target is unavailable because Hardware Radar has no Worker/project runtime configuration target, Cloudflare account identifier binding, or API-token binding. It returns `BLOCKED`, identifies those prerequisites, writes no authorization, performs no network request, and never reads or prints the recipient.

When an isolated target fixture satisfies every prerequisite, PREPARE validates DF005-Q approval, DF005-N provider selection, and DF005-P runtime configuration. It creates a deterministic 15-minute `GATEWAY_ALERT_RECIPIENT_VERIFICATION` authorization bound to approval ID, provider configuration ID, runtime key, verification authority, SHA-256 destination digest, exact operation, and creation time. The authorization stores no plaintext address and explicitly sets single use true, automatic retry false, and sending/provider-deployment/sender-domain authority false. Durable save is idempotent; conflicting state fails closed.

EXECUTE requires `--confirm=VERIFY-ALERT-RECIPIENT` before credential loading, client construction, or provider access. It revalidates expiry and every authorization binding, checks consumption, loads server-only credentials, reserves the single use, and may issue exactly one `POST /accounts/{account_id}/email/routing/addresses` request. Replay returns `ALREADY_CONSUMED`; there is no automatic retry. The operation may cause Cloudflare to send its destination verification email, reported as `VERIFICATION_EMAIL_REQUESTED`, never as an alert email.

Destination creation/request does not establish `VERIFIED`. Recipient state remains `PENDING_VERIFICATION` until the mailbox operator completes Cloudflare's link flow and separate provider-verifiable evidence is captured through the DF005-Q model. Even verified evidence leaves provider deployment, sender/domain configuration, alert sending, Gateway transport, and browser connection disabled. DF005-R performs no production PREPARE, execution, verification request, email, Worker/D1/WAF deployment, sender setup, acquisition, or spend.
