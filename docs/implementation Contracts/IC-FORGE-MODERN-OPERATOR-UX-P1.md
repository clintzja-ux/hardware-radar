# IC-FORGE-MODERN-OPERATOR-UX-P1

## Status

Implemented and fixture-certified. Human one-hour proficiency trial remains pending.

## Doctrine

`FORGE-UX-001 — Modern Operator Experience`: Forge organizes routine work by operator goals—Overview, Products, Retailer & Affiliate Links, Market Operations, Reviews & Exceptions, and Settings / Diagnostics—rather than by internal subsystem names.

`FORGE-UX-002 — One-Hour Operator Proficiency`: a first-time authorized operator should be able to complete representative routine inspection workflows after approximately one hour of familiarization. Automated checks certify navigation, data loading, safety, responsive behavior, and catalog correctness; they do not prove human proficiency.

`HR-OPS-SIMPLICITY-001 — Internal Complexity, External Simplicity` remains authoritative. Presentation may hide deterministic plumbing but cannot hide source identity, uncertainty, consequential authority, or confirmation.

## Composition

The modern shell is a Forge presentation component. It owns no product, destination, affiliate, Current, History, review, publication, or release state. The read-only loopback preview server accepts only GET/HEAD, binds `127.0.0.1`, and serves the existing application plus two ignored certified projections. It has no provider, repository mutation, credential, or privileged browser API.

The Product Manager automatically loads the certified 158-product projection, retains manual file import under Diagnostics, supports full-text brand/name/MPN/ID search, governed filters, sorting, 25-row pagination, one-click details, readable grouped specifications, separate retailer and affiliate presentation, Current/History labels, and truthful missing/unresolved states. Unavailable actions state the missing trusted-runtime boundary and never simulate success.

## One-hour usability protocol

Using the real 158-product projection, a first-time operator attempts: find a named product; identify capacity/configuration; find Amazon or Newegg destination; determine Current availability; locate a missing destination; find pending review; understand last market refresh; locate editing and explain why it is unavailable. Record completion, elapsed time, errors, help requests, navigation difficulty, and interpretation of status messages. Pass requires all eight tasks completed within 60 minutes with no unsafe authority inference and no more than two assistance events. Human execution—not automated testing—is required before claiming proficiency proven.

## Authority

This increment performs no canonical mutation, provider operation, publication, release, or deployment. Manual imports are diagnostic fallback only. The shortest future self-service-write boundary remains an authenticated, auditable trusted operator runtime over existing canonical owners.
