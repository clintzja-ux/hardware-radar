# IC-FORGE-AMAZON-DESTINATION-EXACT-PRODUCT-REVIEW-CONTEXT-P1

## Purpose

Forge presents sufficient canonical evidence for `OPERATOR_EXACT_PRODUCT_REVIEW` without becoming a review or destination authority.

## Ownership and projection

- Atlas remains the sole owner of product specifications.
- `ProductionForgeAmazonDestinationReviewProvider` resolves each preparation's Atlas product and projects a category review context.
- The RAM renderer exposes canonical identity, capacity, performance, electrical, ECC, buffering, lighting, and kit/module facts without inferring missing values.
- Amazon identity, provider-result lineage, rights, collision, destination, and review state remain governed by their existing Mercury owners.

## Local interaction semantics

- Checklist state, reviewer input, and rejection selection exist only in the loaded browser page.
- `REVIEW CHECKLIST COMPLETE` is not `APPROVED`.
- Approval command handoff is enabled only for a current awaiting-review preparation after every approval check and reviewer identity are supplied.
- Rejection command handoff requires reviewer identity and a controlled reason but not a complete approval checklist.
- Command-copy actions produce the existing `mercury:amazon-destination:review` command and perform no shell, repository, network, review, or destination operation.
- Stale and blocked preparations cannot prepare approval handoff.

## Authority boundary

Forge remains read-only. It cannot create review evidence, persist destinations, modify Atlas or Mercury, call providers, grant market/publication authority, or execute commands. Destination persistence remains unavailable until an independently executed governed approval exists.

## Certification

Fixtures cover Atlas-derived RAM context, missing optional values, explicit ASIN and URL presentation, safe links, local checklist transitions, approval/rejection command handoff, controlled reasons, canonical state rendering, automatic discovery, and 200-item scale. The real certified export must retain five awaiting-review preparations and zero review decisions or destination writes.
