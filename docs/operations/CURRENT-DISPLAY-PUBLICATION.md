# Current-display publication operation

Prepare and inspect first. PREPARE derives one exact product scope from canonical state and costs `$0.000`; it does not authorize publication. AUTHORIZE requires the exact confirmation `AUTHORIZE-CURRENT-DISPLAY-PUBLICATION`, revalidates all current facts, and still grants no release authority. Artifact construction and static release PREPARE/INSPECT remain later independent gates.

If prices, freshness, destinations, rights, source conflict, comparison eligibility, snapshot identity, or public facts change, authorization fails closed and a new candidate must be prepared. History is not an input requirement. Affiliate/Rakuten routing is not price truth or publication authority.
