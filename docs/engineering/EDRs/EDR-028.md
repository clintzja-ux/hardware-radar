# EDR-028 — Two-producer dependency verification begins in observation-only shadow mode

**Status:** Proposed / locally validated; not merged or production installed

**Date:** 2026-11-21

**Scope:** Sentinel publication preparation, Atlas specifications, Mercury Current

## Context

The production P2 Foundation can prove whether generated bytes changed, but it cannot prove that all and only the required dependent artifacts changed. A proof of value showed deterministic prediction for Atlas specification and Mercury Current changes and detected unexpected paths, missing dependent paths, and incomplete input bindings with negligible pure-function overhead.

## Decision

Integrate dependency verification at the existing governed preparation owner in observation-only shadow mode for Atlas specifications and Mercury Current. Use the certified candidate and accepted-predecessor portfolio bindings, the existing full generator, existing validation, and existing normalized path inventory. Record diagnostics in existing preparation event evidence while excluding them from checkpoint identity and every eligibility, authority, no-change, and recovery decision.

Mercury History, destination-only planning, selective generation, enforcement, generalized producer services, and new operator commands remain outside this decision.

## Alternatives considered

- Enforce mismatches immediately: rejected because only two producer types have production-shaped parity evidence.
- Introduce a general producer framework: rejected as premature and duplicative.
- Retain byte-delta classification alone: rejected because controlled tests demonstrate missing and unexpected dependency defects that it cannot classify.
- Add no preparation integration: rejected because standalone tests cannot measure parity against the governed normalized inventory.

## Consequences

- Publication behavior remains unchanged while deterministic evidence accumulates.
- Mismatches remain visible but non-blocking.
- The planner declaration must be kept aligned with generator semantics; parity tests protect this risk.
- A later enforcement decision requires measured production-shaped false-positive/false-negative evidence and separate review.

## Affected contracts

- `IC-PUBLICATION-RELIABILITY-P2-FOUNDATION`
- Existing governed live-price preparation and unattended publication event evidence

## ADR review

ADR-012 and ADR-017 remain unchanged. Canonical ownership, authority, orchestration, publication state, and recovery boundaries do not change.
