EDR-006

Title

Platform Codename: Project Nexus

Decision

The internal codename for the Hardware Intelligence Platform is Project Nexus.

Hardware Radar remains the flagship public application built on Project Nexus.

All internal architectural documentation, milestones, engineering sessions, ADRs/EDRs, and design documents will reference the platform as Project Nexus.

Rationale

"Nexus" reflects the platform's role as the central point where structured hardware knowledge, market intelligence, validation, analytics, publishing, and AI reasoning converge into a unified system. The name is technology-agnostic, scalable, and suitable for a long-lived platform.
