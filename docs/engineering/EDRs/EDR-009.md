EDR-009

Engineer one canonical reference record before scaling a repository.

Examples:

Atlas Products

✔ One canonical Corsair RAM product

Atlas Brands

✔ One canonical Corsair brand

Atlas Categories

✔ One canonical DDR5 category

Atlas Retailers

✔ One canonical Amazon retailer

Only after the reference record is approved do we scale to dozens or hundreds of records.

This minimizes duplicated mistakes and keeps every repository internally consistent.
